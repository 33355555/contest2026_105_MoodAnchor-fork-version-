IMU + EDA：训练、个人校准与测试标准流程

一、适用范围
本流程用于后续统一验证 IMU 运动过滤与 EDA 生理确认，不将生理变化描述为医学诊断。
当前已展示的 IMU 原型结果采用随机窗口留出，不能声称已完整执行本流程。
结果来源和两种评估方式的区别见 docs/ALGORITHM_METRICS.md。

二、记录与划分
以 participant_id / session_id / block_id / time_start / time_end 为记录索引，
同步保存 IMU、EDA、标签来源、传感器质量、采样率和佩戴情况。
先按受试者、会话和连续时间块划分数据，再在各块内部提取窗口。
同一原始采样点不得同时用于训练、校准、反馈或盲测。

三、任务与窗口
IMU：运动干扰过滤，不直接识别情绪。100 Hz，2 秒窗口、1 秒步长。
EDA：相对个人静息基线的生理变化确认。4 Hz，5 秒窗口、1 秒步长。
标签纯度、有效信号条件和剔除规则必须预先固定。
反馈/盲测边界的隔离带至少覆盖完整窗口，建议统一采用 5 秒并核查实际采样范围。

四、全局训练
IMU 与 EDA 分别使用各自的源受试者训练。
特征定义、标准化参数、模型权重与全局阈值只由源受试者确定。
使用按受试者留出的内部验证选参数，不读取最终盲测标签。
保存数据版本、参与者清单、随机种子、特征顺序、单位和模型版本。

五、个人校准
在独立低活动/静息时间段采集约 120 秒基线。
IMU 与 EDA 分别计算个人中心和尺度，记录有效采样起止时间。
推荐 median / MAD 等稳健统计；须处理接触不良、饱和和异常大动作。
校准采样点永久排除在反馈和盲测之外。

六、反馈调阈
使用校准后独立时间块，包含目标正样本与困难负样本。
全局分类器权重冻结，只允许调整事先列明的个人对齐参数或决策阈值。
预先确定候选参数、选择标准和评价指标；禁止看过盲测结果后再回调阈值。

七、盲测与报告
使用未参与训练、校准和调参的后续完整时间块。
同一次录制只能称为“会话内时间盲测”；跨日或跨会话须有相应独立数据。
同时报告混淆矩阵、Accuracy、Precision、Recall、F1、真实时长与时间块数量。
重叠窗口数不是独立事件数；真实系统还需评估事件误报、漏报和触发延迟。

八、串行部署
IMU 高运动概率 p < 0.22 时允许 EDA 确认；有效 EDA 输入 p >= 0.68 时生成事件，
确认后冷却 30 秒。以上是待验证的部署参数，并不等于个人化结果的评价阈值。
PAMAP2 与 WESAD 并非同批同步采集，不能组合两组离线指标宣称端到端性能。
需要同步自采 IMU + EDA 数据，验证窗口、单位、时序与传感器质量后再评估整体系统。

九、部署状态
embedded/mood_gate 提供端侧核心，平台读取函数仍待接入；当前主应用使用规则阈值链路。
App 的固定演示分数只用于交互展示，不参与算法性能评价。
